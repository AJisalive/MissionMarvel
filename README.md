# Mission Marvel

Mission Marvel is a personal Marvel watchlist for the films you want to see before Doomsday.

## Run it

```bash
npm install
npm run dev
```

## Poster catalogue

The built-in Marvel catalogue and movie search use Wikipedia's public API for poster thumbnails. No account, API key, or setup is required.

## Android

```bash
npm run build
npm run cap:sync
npm run cap:android
```

## Download

[Download Mission Marvel v0.1.0 for Android (APK)](https://github.com/AJisalive/MissionMarvel/releases/download/v0.1.0/Mission-Marvel-v0.1.0.apk)

This is a debug APK for direct installation. Android may ask you to allow your browser or file manager to install unknown apps.

Poster images and film summaries are supplied by Wikipedia.
