# Changelog

All notable changes to Mission Marvel are documented in this file.

## [Unreleased]

### Added

- Personal notes for each film, including a drawer for rewatch reasons and post-watch reactions.

## [0.1.2] - 2026-10-24

### Added

- Remove action for films in the personal watchlist and catalogue.
- Mission Marvel launcher icon concepts.

### Changed

- Long movie titles now wrap instead of overflowing their watchlist cards.
- Android project files are no longer tracked in the repository.

## [0.1.0] - 2026-10-24

### Added

- Initial Mission Marvel release.
- Personal Marvel watchlist with watched status and 1-10 ratings.
- Built-in Marvel film catalogue and search backed by Wikipedia poster metadata.
- Manual film entry.
- Android debug APK download.
